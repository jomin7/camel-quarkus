=== Usage

The Stripe component provides integration with the https://stripe.com/[Stripe] payment platform API.
This extension wraps the Camel Stripe component for use in Quarkus applications with full native compilation support.

==== Configuration

You can configure the Stripe API key at the component level:

[source,properties]
----
camel.component.stripe.api-key=sk_test_...
----

Or pass it as an environment variable:

[source,bash]
----
export STRIPE_API_KEY=sk_test_...
----

==== Basic Example

[source,java]
----
from("direct:createCustomer")
    .setBody(constant(Map.of(
        "email", "customer@example.com",
        "name", "John Doe"
    )))
    .to("stripe:customers")
    .log("Created customer: ${body.id}");
----

==== Supported Operations

The extension supports all Stripe operations available in the Camel Stripe component:

* `customers` - Create, retrieve, update, delete, and list customers
* `paymentIntents` - Create, retrieve, update, cancel, and list payment intents
* `products` - Create, retrieve, update, delete, and list products
* `prices` - Create, retrieve, update, and list prices
* `subscriptions` - Create, retrieve, update, cancel, and list subscriptions
* `invoices` - Create, retrieve, update, and list invoices
* `charges` - Create, retrieve, update, list, and capture charges
* `refunds` - Create, retrieve, update, and list refunds
* `paymentMethods` - Create, retrieve, update, and list payment methods
* `balanceTransactions` - Retrieve and list balance transactions

For more details, refer to the xref:reference/extensions/stripe.adoc[Stripe extension reference].

==== Authentication

Always use test mode API keys (starting with `sk_test_`) for development and testing.
Never commit API keys to version control.

For production deployments, configure the API key using environment variables or a secure secrets management solution.
